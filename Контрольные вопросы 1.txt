Чем uv run лучше, чем просто python hello.py в глобальном окружении?
Такой запуск уменьшает риск,  что из-за ошибок кода будет повреждена компьютерная система.

Зачем нужны type hints, если Python и так динамический?
Про это не было разобрано подробно на уроке, но предположу, что это нужно отслеживать использоание праильных типов переменых в функциях.
Я проверил - VS Code не подчеркивает, если в функцию подать переменную неправильного типа. Возможно для этого есть спеууиальные расширения.

Что произойдёт, если импортировать hello.py из другого файла без if __name__ == "__main__":?
Импортируются только объявленные до этой строчки функции, переменные и классы. Код после это строчки не запустится.
